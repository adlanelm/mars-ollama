# Recursive Flint 40B-A2.5B vs qwen3.6-35b-a3b, 2026-10-24

Candidate: `unsloth/flint-GGUF` UD-Q4_K_XL (25.05 GB), MoE 39.8B / ~2.5B active, text only, released 2026-10-21
(llama.cpp support PR #30928 is in b11804). Baseline: `qwen3.6-35b-a3b` UD-Q4_K_XL (22.36 GB), run 2026-10-22 on the same
build and flags. Both at 128k, production sampling. Result: **Flint is pi's default; qwen3.6 stays for vision.**

## Fit and speed

| MoE cache | Flint tg (1.3k-token essay) | RAM available |
|---|---|---|
| none | 31.7 tok/s | 11.3 GiB |
| **1024 MiB** | **35.2 tok/s** | 10.6 GiB |
| 2048 / 3072 MiB | `radv/amdgpu: Not enough memory for command submission`, `ErrorDeviceLost` at load | |

qwen3.6 with 3072 MiB: 46 tok/s. Prompt: the 25k-token needle task took 18-24 s on Flint, 24-33 s on qwen3.6.

## bench/suite.py (30 tasks x 2 samples, 16k max tokens)

| model | math | logic | code | instruct | tools | longctx | overall | think tok/task | s/task | truncated |
|---|---|---|---|---|---|---|---|---|---|---|
| qwen3.6 | 57% | 100% | 87% | 100% | 100% | 100% | 87% | 5,709 | 130 | 7/60 |
| **Flint** | 100% | 100% | 100% | 100% | 100% | 75% | **98%** | 1,594 | **51** | 1/60 |

All 7 qwen3.6 losses were truncations at 16,384 thinking tokens. Rerun of those tasks (both samples) at 64k max tokens:
10/10 correct, 19,256 thinking tokens and 442 s per task on average (m-digits 38-43k tokens, 15-16 min); Flint on the same
tasks: 2,818 tokens, 85 s. With the rerun merged, qwen3.6 also scores 98% (152 s/task, 6,556 thinking tokens).

Flint's miss: x-multi sample 1 thought to 16,383 tokens without an answer (sample 0 correct in 36 s). qwen3.6's remaining
misses: c-expr (1/16 tests) and c-glob (6/7), wrong code, not truncation.

## Thinking control

Flint's template ignores `reasoning_effort` and `enable_thinking`; it always thinks. llama-server's `thinking_budget_tokens`
works: at the limit the reasoning ends with the `--reasoning-budget-message` text and the model answers (budget 64 on the
inclusion-exclusion task: answered 240 instead of 401). Budget 0 = no thinking.
